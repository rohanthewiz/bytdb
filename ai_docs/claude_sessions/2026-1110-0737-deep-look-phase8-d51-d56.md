## Decisions

- **Readable errors = Postgres wording in the message**, not fields
  appended to `Error()`: pgwire sends `Error()` as the message and the
  fields as Detail, so appending would have duplicated them on the wire.
  `ErrText` still renders fields. Tests matching old phrases were updated.
- **regclass has no value type**: only a top-level select item (and
  `::text`) renders a name; elsewhere it stays the oid so comparisons work.
  Documented, with `::regclass::text` as the workaround.
- **No new test dependencies**: lib/pq and goose statements are sent through
  pgx, copied verbatim with source versions cited, rather than adding
  modules. GORM v2, golang-migrate and atlas were not available offline and
  were left out rather than written from memory (noted in N-043).
- **`setval` on an identity's implied sequence** moves its counter, which
  pg_dump's setval lines need; sequence names accept `public.`.
- **Advisory/session function arguments** cast untyped placeholders
  (bigint, bool) so Describe reports the right type.

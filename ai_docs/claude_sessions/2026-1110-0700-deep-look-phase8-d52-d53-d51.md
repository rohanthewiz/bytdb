## Decisions

- **Advisory lock scope** is one `DB` value (every connection of a wire
  server). No deadlock detector: waits end at `statement_timeout` or cancel.
  Shared-mode locks not implemented. Documented in features and gotchas.
- **Function state rides the DB copies** (`DB.ss`, like `DB.seq`), so
  registry functions gained an `envEval` form instead of a parallel switch.
- **`ORDER BY` inside non-collecting aggregates** is accepted and ignored,
  as Postgres accepts it; the extended aggregate forms are refused as
  window functions.
- **`SET TRANSACTION READ WRITE` in a READ ONLY block** is refused (25006):
  the block began without the writer lock.
- **Bare `user`** follows Postgres (a reserved word there), so it now reads
  as the session user even where a table has a column of that name; no test
  or doc used one.
- **`numeric` columns are refused in CREATE TABLE** ("unknown column
  type"), found while probing D-51. Not in the plan: raised as N-048 rather
  than decided here, because mapping it to float8 would be lossy for money.

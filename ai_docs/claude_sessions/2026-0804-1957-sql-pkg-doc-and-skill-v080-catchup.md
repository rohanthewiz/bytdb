## sql/sql.go package doc

Stale text rewritten:

- Closing transactions paragraph is now mode-aware: single-writer
  default (serializable by construction, writer lock from BEGIN to
  end) vs `WithConcurrentWrites` (snapshot-isolation OCC,
  first-committer-wins, `bytdb.ErrTxConflict` / SQLSTATE 40001 with
  retry hint, autocommit retried silently ~3x, blocks never retried
  server-side, SERIALIZABLE opt-up via read-set validation through
  BEGIN / SET TRANSACTION / default_transaction_isolation, SHOW
  reporting the real mode, DDL escalating to an exclusive stall and
  never returning 40001).
- Sequences paragraph: allocation transactional in default mode,
  gap-tolerant Postgres-style under concurrent writes (counter-key
  conflict rationale included).

  expressions (`nextval` inline works; verified against
  `sql/insert_expr_test.go`), column references still don't resolve.

Never-documented features added (semantics sourced from the feature

`docs/gotchas.md`):
